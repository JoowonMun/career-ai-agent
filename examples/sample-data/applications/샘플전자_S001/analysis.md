# 샘플전자 | AI 엔지니어 (LLM 서비스) 분석

> 샘플전자는 예시용 가상 기업이라 웹 검색 결과가 없다. 모든 내용은 공고 본문 기준이다.

## 요약
- 회사 한 줄 소개: 사내 LLM 기반 검색·질의응답 서비스를 만들고 운영하려는 회사 (공고 본문)
- 지원 이유: 사내 문서 RAG 검색과 모델 배포 자동화를 직접 해 본 경험이 주요 업무와 그대로 겹친다.
- 내 경험과 맞는 점:
  1. RAG 검색 구축과 평가 세트 기반 품질 개선 (projects/rag-search.md)
  2. Airflow·MLflow 기반 배포 자동화와 자동 롤백 (projects/mlops-pipeline.md)
  3. Python 4년, Kubernetes 사용 경험 (profile.md)

## 기업 개요
- 공시 없음 (DART 검색 결과 없음, 가상 기업)

## 사업 구조
- 사내용 LLM 검색·질의응답 서비스를 개발 중 (공고 본문)
- 모델 배포·운영 자동화를 함께 맡길 인력을 찾음 (공고 본문)

## AX·데이터 동향
- 공개 자료 없음(가상 기업). 공고상 사내 업무에 LLM을 도입하는 단계로 보인다 (공고 본문).

## 적합도: 상
근거: 자격 요건 3개와 우대 사항 2개 모두 경험 뱅크에 근거가 있다. Kubernetes는 "운영" 경험이라 하기에는 근거가 배포 파이프라인 사용에 그친다.
