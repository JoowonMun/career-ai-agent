# 샘플전자 | AI 엔지니어 (LLM 서비스) 경력기술서

## 강조 전략

### 배치 순서
1. 사내 규정 문서 RAG 검색 — 앞세울 측면: 평가 세트 기반 검색 품질 개선
2. 수요 예측 모델 배포 자동화 — 앞세울 측면: 배포·운영 자동화와 자동 롤백
3. 구독 고객 이탈 요인 분석 — 한 줄로 축소

### 줄이거나 뺄 경험
- 구독 고객 이탈 요인 분석: LLM 서비스와 거리가 멀어 한 줄로 줄인다. 데이터 분석 역량을 보여 주는 용도로만 남긴다.

### 채우기 어려운 요구 역량
- Kubernetes 운영: 경험 뱅크에는 배포 파이프라인에서 쓴 기록만 있고 클러스터 운영 기록은 없다. 면접에서는 사용 범위를 정확히 말하고, 운영 경험은 없다고 밝힌다.

## 맞춤 경력기술서

### 경력 요약
사내 규정 문서 RAG 검색과 ML 모델 배포 자동화를 직접 구축한 4년 차 ML 엔지니어입니다. 평가 질문 300개를 먼저 만들고 매주 측정해 정답 조항 포함률을 61%에서 87%로 높였습니다. 재학습부터 배포까지 자동화해 배포 주기를 2주에서 1일로 줄였습니다.

### 핵심 역량
- RAG 시스템 구축: 조항 단위 분할, 하이브리드 검색(BM25+임베딩), 재순위 적용 (사내 규정 문서 RAG 검색)
- MLOps: Airflow 재학습 파이프라인, MLflow 모델 버전 관리, 성능 기준 자동 롤백 (수요 예측 모델 배포 자동화)
- Python: 4년 2개월, 전 프로젝트의 주 언어
- 평가 체계 설계: 평가 질문 300개 구축, 매주 정확도 측정 (사내 규정 문서 RAG 검색)
- Kubernetes: 배포 파이프라인에서 사용 (수요 예측 모델 배포 자동화)
