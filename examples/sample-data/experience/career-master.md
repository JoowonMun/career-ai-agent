# 기본 경력기술서

## 경력 요약
가상물산에서 4년간 데이터 엔지니어와 ML 엔지니어로 일했습니다. 사내 규정 문서 RAG 검색을 구축해 정답 포함률을 61%에서 87%로 높였고, 수요 예측 모델의 재학습·배포를 자동화해 배포 주기를 2주에서 1일로 줄였습니다. 평가 기준을 먼저 세우고 수치로 개선하는 방식으로 일합니다.

## 경력 사항

### 가상물산 | 데이터 엔지니어 → ML 엔지니어 | 2022.08 ~ 현재
- 담당 업무: 사내 문서 검색 서비스, ML 모델 배포 파이프라인, 고객 데이터 분석
- [사내 규정 문서 RAG 검색] 백엔드·검색 품질 담당 · 조항 단위 분할, 하이브리드 검색과 재순위, 평가 질문 300개 구축 · 상위 5개 정답 포함률 61% → 87%, 규정 문의 월 140건 → 60건 · Python, LangChain, OpenSearch, FastAPI → projects/rag-search.md
- [수요 예측 모델 배포 자동화] 파이프라인 설계·구현 · Airflow 재학습, MLflow 버전 관리, 성능 기준 자동 롤백 · 배포 주기 2주 → 1일, 성능 저하 사고 분기 3건 → 0건 · Airflow, MLflow, Docker, Kubernetes → projects/mlops-pipeline.md
- [구독 고객 이탈 요인 분석] 단독 분석 · 이탈 예측 모델과 SHAP 해석, 온보딩 개편 제안 · 해당 구간 이탈률 18% → 13% · SQL, pandas, scikit-learn → projects/churn-analysis.md
